## 로컬 확인

1. 백엔드 서버와 DB를 준비하고 `http://127.0.0.1:8080/api/routes`가 응답하는지 확인한다.
2. `frontend`에서 `npm run smoke:api`로 공개 조회 API를 검사한다. 시드 데이터가 있으면 7종을 모두 검사하며, 노선 또는 충전소가 없으면 연관 API는 건너뛴다.
3. `npm run dev:api`로 프론트를 실행해 실제 API 경로를 확인한다. 이 모드에서는 DEV 시연값으로 대체하지 않는다.
4. 실제 응답에 맞춰 1→2→3 순서로 화면을 검증하고 D01은 인증·접근 정책 확정 후 진행한다.

## 2026-11-10 로컬 검증 결과

저장소의 `backend/scripts/demo/seed_demo.sql`을 **새 Compose 프로젝트 `evision-frontend-integration`의 전용 DB 볼륨**에만 적재했다. 기존 DB·볼륨은 사용하지 않았고, 자동 수집과 이력 정리는 껐다. 시드에는 충전소 12곳, 충전기 26대, 30분 점유 기록 14,784건, 예측 기록 39건이 들어 있다. 충전소·충전기·상태·예측값은 가짜 시연 데이터다.

`npm run smoke:api`로 공개 조회 7종이 실제 백엔드에서 모두 응답함을 확인했다. 노선 1개, 운영기관 1개, 서비스 대상 충전소 11곳, 추천 5곳을 조회했다. `dev:api` 화면에서 경로 목록, 충전소 상세, 선호 운영기관, 즐겨찾기 2곳, 추천·비교를 확인했다. 시드에는 상태 변경 이력이 없어 M11의 빈 상태를 확인했다. D01 API는 직접 `NO_RECORDS` 응답을 확인했지만, 운영자 인증이 없어 PRD 운영 화면은 계속 차단한다.

## 2026-11-11 카카오맵 검증 결과

등록된 `http://127.0.0.1:5173`에서 PRD API 모드를 임시 실행해 M03 카카오맵 타일과 시드 충전소 마커를 함께 확인했다. 지도 타일 19개, 현재 범위 충전소 4곳과 마커 4개가 표시됐으며, 마커를 누르면 해당 충전소 카드가 선택됐다. 검증 후 5173 서버는 기존 DEV 모드로 복구했다.

`http://127.0.0.1:5185`에서는 처음 SDK 로딩이 실패했으나, 11월 11일 재검증에서 지도 타일과 현재 위치 마커가 표시됐다. 따라서 포트 등록 문제로 확정할 수 없다. 현재 위치 요청은 처음에 10초 제한으로 시간 초과됐고, 재시도 후 성공해 지도가 해당 위치로 이동했다. 현재 범위의 충전소 0곳은 로컬 데모 데이터 조회 결과다. 실제 공공데이터가 쌓인 운영 서버와의 통합 검증은 아직 하지 않았다. 계정 정보와 공공 API 키는 Git에 넣지 않는다.
